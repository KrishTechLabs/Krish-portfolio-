KRISH RAJ — PREMIUM PORTFOLIO
==============================

FILES
- index.html : website content and page structure
- style.css  : design, responsive layout, neon/cyberpunk styling
- script.js  : mobile navigation, reveal animations, footer year
- anime-hero.jpg : anime/cyberpunk artwork used in the hero panel

PREVIEW ON ANDROID
1. Extract the ZIP.
2. Open index.html in a mobile code editor that supports HTML preview, or upload the three files to a static host.
3. Keep index.html, style.css, script.js, and anime-hero.jpg in the same folder.

PUBLISH
- GitHub Pages: create a repository, upload all three files to the repository root, then enable Pages in Settings.
- Netlify: deploy the folder containing index.html (not a parent folder that hides it).

CUSTOMIZE
- Edit text and links in index.html.
- Change colors in the :root section at the top of style.css.
- Replace anime-hero.jpg with a different artwork file using the same filename if you want to change the hero image. Replace the CSS-made project illustrations with your own real project photos when available.

NOTE
This is a front-end portfolio starter. Project illustrations are CSS artwork, not photographs of your actual builds. The alcohol detection project is described as an educational model, not a certified breathalyzer.
